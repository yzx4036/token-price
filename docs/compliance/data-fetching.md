# 数据抓取与展示合规纪律

本文件是站点取数的对外合规依据，改动抓取实现或展示文案前先读这一页。
判断口径：价格数字是**厂商主动公开的商业信息**，本站是信息聚合与估算工具，
不是厂商、也没有获得任何厂商授权。

## 一、抓取侧五条

1. **不许绕反爬**。遇到 403、Cloudflare 挑战、验证码、登录墙，一律停手，标记「未取到」，
   不换 UA、不换浏览器指纹、不使用代理池硬闯。这一条是刑民分界线：
   《刑法》第 285 条非法获取计算机信息系统数据罪的前提是「侵入」或「采用其他技术手段」。
2. **抓前读 robots.txt**，Disallow 命中即放弃该路径；robots 返回 404（无规则）的站点按宽松处理，
   但仍遵守下一条限频。
3. **带可识别 UA + 限频**：UA 里带站点名与联系方式，单站 ≤1 req/s，批量任务分批执行，
   不做并发压测式抓取。
4. **只存字段**：价格、币种、计价条件、来源 URL、抓取时间。不存整页 HTML、不重发厂商原文，
   不复制厂商定价页的表格编排与说明文案（价格数字属事实，表述受著作权保护）。
5. **不做镜像、不做替代**：页面上逐条给源链接与抓取日期，用户要买仍回厂商。
   判例把「实质性替代」作为核心尺子（大众点评诉百度、淘宝诉美景）。

## 二、法条与判例口径（2026-11 核对）

- 《反不正当竞争法》2025-06-27 修订、**2025-10-15 施行**，第 13 条第 3 款（数据专条）：
  不得「以欺诈、胁迫、避开或者破坏技术管理措施等不正当方式，获取、使用其他经营者合法持有的数据，
  损害其他经营者的合法权益，扰乱市场竞争秩序」。四要件需同时满足；本站因「不绕技术措施」
  卡在手段要件上，不落入该条。
- robots 协议在国内不是独立违法依据，但违反会作为认定「不正当」的重要因素（腾讯诉字节微信数据案）；
  遵守 robots 是加分项。
- 价格数字属事实，不受著作权保护；受保护的是厂商定价页的文字表述与表格编排。
- 本站无个人信息，PIPL 不适用；公开定价页不属「重要数据」，数据安全法风险低。

## 三、展示侧三条（与 #12 同步）

1. **不得暗示官方背书**：溯源等级统一用「官方页抓取 / 聚合数据」，禁止回到「官方核验」「官方原价」
   ——这两个词会被读成本站已获厂商确认（《商标法》第 57 条、《反不正当竞争法》第 6 条的混淆风险）。
   术语常量集中在 `src/lib/copy.ts`，`tests/copy.test.ts` 会拦住写回旧词。
2. **不得代厂商表态**：厂商条款只作转述并标明来源，不与本站计算结论混排。
3. **免责四要素**：非官方 / 与厂商无隶属或授权关系 / 以厂商页面与账单为准 / 不构成采购建议 + 商标归属。
   统一由 `src/lib/site-meta.ts` 的 `SITE_DISCLAIMER` 提供，不要各页各写一份。

## 四、收到异议时的处置

1. 先下架被点名的厂商条目（保留其余数据），2 周内不重新抓取该站。
2. 记录来源：函件/邮件/投诉原文与时间，落 `docs/compliance/` 归档。
3. 下架后仍保留 `/sources/` 页的历史说明，避免读者以为数据从未收录。

> 本文件是工程侧合规口径，不是法律意见；对外主张合法性请走律师意见。

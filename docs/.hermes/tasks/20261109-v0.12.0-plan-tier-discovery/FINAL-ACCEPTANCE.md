## 四、未达标项（如实登记）

| 项 | 设计预估 | 实测 | 原因 |
|---|---|---|---|
| 一致档位 | 22/55 | **6/55** | 38 档卡在「月费集合不完整」：baidu / openai / google / aliyun / tencent / zhipu 等页面把价格放在内嵌 JSON 或图片里，文本与表格通道都抽不到；只有 anthropic / github / stepfun / volcengine / opencode 这些能解析 |
| zhipu / kimi | 不可用 | 一致（`.md`、`llms.txt` 均为 SPA 壳） | 与设计结论一致 |
| xAI | 未提 | HTTP 403 | 新增发现：`x.ai/pricing` 对脚本 UA 直接 403 |

**结论：降噪目标达成（噪音 61 → 0 高置信），覆盖率目标只部分达成。** 要让 baidu/openai/google 这些家进榜，需要为每家写内嵌 JSON 适配器——那已超出「一个迭代」的范围，登记为后续工作。

## 五、失败 → 返工链（编排层直改中的 4 次修正）

| 现象 | 根因 | 修法 |
|---|---|---|
| 高置信候选 7 条全是 Copilot 的 5/15/19/31/70/200 | 值级合并只留「最优一项」，`monthly` 压过 `conflict` | `foldTokens` 改为按值收集**全部**归类，改用不对称判据（已录宽松、未录严格） |
| Anthropic ¥500 判成干净月费 | 前窗口含上个价格的 `/ MTok` → `unit` 先短路 | R5 单价判定只看数字**之后** |

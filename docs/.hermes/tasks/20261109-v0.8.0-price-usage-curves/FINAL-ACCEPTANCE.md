## 二、逐项验收结论与证据

### 2.1 门禁（编排层亲跑）

### 2.2 图表可读性探针（本轮新写的机器判据）

`node scripts/qa/chart-probe.mjs --url <页面> --viewport 320,375,414,768,1440` → **五个视口全部 PASS**

| 视口 | 可见 SVG | 横向溢出 | 有效字号 | 文字重叠 | 文字裁切 |

| 320 | 7 | 0 | 12.0px | 0 | 0 |

| 414 | 7 | 0 | 14.0px | 0 | 0 |

判据：同图内 `<text>` 的 bounding box 两两不相交（容差 2px）、文字不出 svg 边界、有效字号（用户单位 × 缩放）≥ 11px。

### 2.3 静态可渲染（禁用 JS）

`dist/api-pricing/index.html`：**14 个 `<svg>`**（桌面层 7 + 移动层 7）、`NaN/Infinity/undefined` 命中 **0**、「月（对数）」4 处、历史空态文案存在、走势图无折线 `path`（符合 D8）。

### 2.4 数据正确性

- 散点：`146 条无评测数据未入图；0 条缺可比正价未入图`，与 178 − 32 = 146 一致；缺分不入图。
- 构成：每币种展示 8 条（桌面）/4 条（移动），写出「展示 N/总数」，缺 `cacheWritePrice` 只标注不补零。
- 用量-成本：`33` 组保本对可算，图内实线/阶梯线/交点齐全；纵轴对数后 1M–1000M 全区间可读（R1）。
- 跨币种：各图按 `billingCurrency` 分面，前沿与交点只在同币种内计算（审查 A4 复核通过）。

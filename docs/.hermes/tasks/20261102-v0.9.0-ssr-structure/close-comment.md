## 决定：选 A，接受现状并关闭

按方案 A 处理——跳变确认为**一次性、发生在 hydration 时刻、页面不崩**，且降级态是桌面 3 列网格（可读、无横滚），两条彻底修法的代价都大于收益：

- 双结构 CSS 显隐：DOM 8,749 → 约 15,000 节点，本页已在 Lighthouse「DOM 过大」红灯（阈值 1400）之外，翻倍是拿体验换更实的性能问题
- 单表格 + 移动端重排：架构更好，但等于把现有移动端卡片整体换成 data-label 重排表格行，属可见产品改版，不在本条范围

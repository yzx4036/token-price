# 需求追加 R-03：国际厂商以美元为主展示，人民币仅作估算副列

> 追加于 2026-10-31，优先级高于 `requirements.md` §1.1 中「人民币为主列」的表述。
> 用户的原始要求：**「国外主要标美元，但在美元后边大约人民币估算（汇率随时变化，不准确）」**

## 规则

### 国际厂商（`billingCurrency = USD`）

- **主价格 = 美元原价**，例如 `$2.00 /1M`。价格列、排序、表格默认排序键全部按美元值。
- **美元后面紧跟人民币估算**，形式：`≈ ¥13.34（按 6.6696 估算 · 2026-10-31）`。
- 文案必须出现「估算」二字，且必须带汇率与日期；不得写成「¥13.34」单值，也不得写成「官方价 ¥13.34」。
- 页脚 / methodology / sources 必须有一句明确免责：**汇率随时变化，人民币值仅供粗略参考，不准确，最终账单以美元为准。**

### 国内厂商（`billingCurrency = CNY`）

- **主价格 = 人民币原价**，标「官方原价」。
- **不显示美元**，也不做反向换算（避免伪造不存在的美元挂牌价）。

### 计算器

- 输入区可同时输入 token 用量，输出区**双列**：`美元成本` 为主（国际厂商），`≈ 人民币` 为辅并带估算标注。
- 选中模型属于国内厂商时，输出以人民币为主，不带估算标注。
- 缺汇率时：仍然 fail closed（不得给出 0 或旧值），提示语说明「汇率数据缺失，无法给出人民币估算，美元结果可用」。

### 排序

- 表格默认按**成本可比性**排序：同一厂商内按 `billingCurrency` 原值排序；跨厂商「最低价」排行榜**不得直接混排 USD 与 CNY**（除非用估算汇率并显式标注「按估算汇率折算」）。

## 验收

- 构建产物中，国际厂商行必须同时含 `$` 原价与 `≈ ¥` 估算；国内厂商行必须是 ¥ 且不含「估算」字样。
- grep 检查：`官方价 ¥` 或 `官方原价 ¥` 出现在 `billingCurrency=USD` 的行 → 判失败。
- 汇率文案必须含「估算」与日期；缺一处判失败。

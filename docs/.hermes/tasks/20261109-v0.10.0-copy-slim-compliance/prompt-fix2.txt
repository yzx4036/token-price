## H1 流程事实被改错（High，《数据来源》页）

`src/views/SourcesView.vue` 当前句自相矛盾：

> 官方页价格不走自动抓取——各家定价页改版频繁，机器判定容易误伤，这部分改为脚本抓取、人工复核后入库

**半句说不走自动抓取，后半句又说改为脚本抓取。** 而且「脚本抓取」这个说法也是错的。

**已核实的真实链路（编排层亲验，以此为准，不许自己推断）**：
- `.github/workflows/data-refresh.yml` 自动跑的是：汇率（`cli.mjs rate`）、聚合快照（`cli.mjs pull`）、派生重建、数据校验、官方价格历史快照。
- **官方页价格本体不在自动流程里**：由维护者用 `scripts/data/cli.mjs add`（`--source-url` / `--verified-at` 必填，见 `scripts/data/lib/add.mjs` 的 `ADD_USAGE`）人工逐条录入，入库前跑校验。
- 脚本只做**差异比对**，把官方值与聚合值偏差大的厂商挑出来复核。

**改成类似**（可用你自己的措辞，但三个事实必须都在）：官方页价格不自动抓取（定价页改版频繁、机器判定易误伤）；这部分由人工逐条录入，每条带来源 URL 与抓取日期，入库前过数据校验；脚本只做差异比对，挑出偏差大的厂商复核。

同时**全站复扫**「人工核对 / 脚本抓取 / 自动抓取 / 爬虫抓取后入库」这类表述，凡与本链路不符的一并改对（包括 `关于本站` 段的「价格由爬虫从厂商官方定价页抓取后入库」——这句也把人工录入说成了全自动）。

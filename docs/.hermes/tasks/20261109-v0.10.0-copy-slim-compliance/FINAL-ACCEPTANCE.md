## 五、本轮最重要的教训（写给下一迭代）

**文案迭代的「事实等价性」无法靠字数与门禁守。** 本轮在「门禁 6/6 + `--compare` 退出码 0 + 图表探针五档全过」三绿的状态下，仍然存在把「人工逐条录入」写成「脚本抓取」这种事实级错误——所有机器判据都查不出来，是对抗审查把 `data-refresh.yml` 与 `add.mjs` 摆在一起看才发现的。

因此本迭代新增了两条**结构性防线**：
1. `copy-guard` 的要素校验改用**独立硬编码 needle 组**，不再引用文案常量本身（自证式断言等于没有断言）；
2. 审查第一号攻击面固定为「语义漂移：新句与旧句的事实是否等价」，要求逐条给 file:line。
